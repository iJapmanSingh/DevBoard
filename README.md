# 🚀 DevBoard

A full-stack MERN application for tracking coding progress, managing tasks, and maintaining developer profiles.

## 🌐 Live Demo

Frontend: https://dev-board-nine.vercel.app

Backend: https://devboard-backend-qj6c.onrender.com

## ✨ Features

- 🔐 JWT Authentication
- 👤 User Profile Management
- 📊 Coding Dashboard
- 📝 Task Management
- 🏆 LeetCode & Codeforces Integration
- ☁️ Deployed on Vercel, Render & MongoDB Atlas

## 🛠 Tech Stack

- React + Vite
- Tailwind CSS
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- Axios

## 🚀 Run Locally

```bash
# Client
cd Client
npm install
npm run dev

# Server
cd Server
npm install
npm start
```
